Claude Code config leaks secrets; MCP and Agent toolchains keep heating up

Highlights

Claude Code leaks secrets

Claude Code's "Don't ask again" option writes commands containing passwords in plaintext into .claude/settings.local.json, and 1,379 secrets have been found across 1,122 public GitHub files. Developers building AI coding assistant extensions can ride this wave by making small config scanning/redaction tools, or by blocking persistence of sensitive commands by default in their own plugins.

Claude Code's "Don't Ask Again" exposes passwords in 1,122 public GitHub filesClaude Code's "Don't ask again" leaks secrets to GitHub — 1,379 secrets in 1,122 public files - Dev & Gadget Note

MCP resurgence and Agent infrastructure

A Japanese community analysis of why MCP is making a comeback: the reasons CLI gained support, the July 28, 2026 statelessness change, and changes like deferred tool loading/code execution; meanwhile AXL claims to offer 1,200+ actions via MCP, and agent-browser and anthropics/skills are also Trending. For people building browser extensions and small tools, this is a clear signal: packaging features as MCP tools or Agent Skills can capture a wave of distribution upside.

Agent memory and observability

One article argues that Agent memory needs its own OpenTelemetry moment, while billion-context offers a context compression plugin for ultra-long sessions. Small-tool developers can build lightweight session memory export, compression, or debug panels as differentiating selling points for plugins.

Local small models and low-cost deployment

Llama-modchip runs 284B DeepSeek on 64GB of RAM with no GPU, and there are also cases of a $10 OpenStick homelab and a clinic building its own local LLM. Those building productivity tools could consider "local-first/offline optional" as a privacy selling point, especially for industry users sensitive about data leaving their premises.
